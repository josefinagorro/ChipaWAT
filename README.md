# ChipaWAT

App web para organizar una convivencia de viaje: casa, perfiles, gastos, calendario, compras, tareas y recordatorios.

## Estructura

- `frontend`: app React con Vite.
- `backend`: API Node.js con Express.

## Primer objetivo

Construir un panel inicial simple y lindo donde cada integrante pueda ver:

- resumen de la casa
- deuda pendiente
- proximos eventos
- compras/tareas compartidas
- notificaciones internas

## Comandos

```bash
npm install
npm run dev
```

Tambien se puede correr cada parte por separado:

```bash
npm run dev:frontend
npm run dev:backend
```
